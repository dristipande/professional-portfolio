How to publish this portfolio on GitHub Pages (free)
1. Create a new public repository on GitHub, for example "portfolio".
2. Upload everything in this folder (index.html, the slides folder, and the files folder).
3. In the repository, open Settings > Pages, set Source to "Deploy from a branch", choose the main branch and the / (root) folder, and save.
4. After a minute or two your site is live at https://YOUR-USERNAME.github.io/portfolio/
5. Paste that link into your Brightspace assignment.
